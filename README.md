# NDM DevOps test

Цепочка nginx-прокси с корректной передачей X-Forwarded-For и защитой от спуфинга.

## Запуск

```
docker compose up -d
```

Порты 8081–8083, глубина цепочки 1–3 прокси соответственно.

## Как устроено

`geo` определяет доверенные IP (сами nginx). `map` на их основе либо дописывает адрес к XFF, либо перезаписывает его — если источник недоверенный.
